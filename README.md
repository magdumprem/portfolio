# Prem Shrenik Magdum — Portfolio

A responsive, dark-themed personal portfolio built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — page content
- `style.css` — responsive styling
- `script.js` — mobile navigation and footer year

## GitHub Pages deployment
1. Create a **public** GitHub repository named `prem-portfolio`.
2. Upload `index.html`, `style.css`, and `script.js` to the root of the `main` branch.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, then **main** and **/(root)**. Save.
5. Wait for publishing and click **Visit site**. Expected URL: `https://magdumprem.github.io/prem-portfolio/` (verify before sharing).

## Local preview
Open `index.html` in a browser, or run `python -m http.server 8000` in this directory and visit `http://localhost:8000`.
